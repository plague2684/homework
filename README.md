#Домашняя работа по банковским операциям

##Цель проекта:
Создать новых фич для личного кабинета крупного банка

##Модули:
  *masks
  *widget
  *processing

##masks:
Выпоняет сокрытие части номера карты(счета)

##widget:
Улучшенная версия masks, а так же преобразует дату в нужный формат

##processing:
Ищет необходимые операции по ключевому слову и сортирует по дате операции

##Дополнительные установки:
Все необходимые дополнения(а так же версии программ) прописаны в файле pyproject
